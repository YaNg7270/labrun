# 统一设计规范 v0.1

适用：安卓 App 与电脑工具。两端共享本文件的颜色、字号层级、术语、时间显示与状态表达；布局分别适配触控与鼠标键盘，不要求逐像素一致。代码中的对应实现：安卓 `android/.../ui/Theme.kt`，电脑端实现时同名令牌。

## 1. 颜色令牌

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `primary` | `#0F6E6E` | `#5DC8C3` | 主操作、当前步骤、进行中 |
| `onPrimary` | `#FFFFFF` | `#00201F` | 主按钮文字 |
| `bg` | `#F6F7F6` | `#101413` | 页面背景 |
| `surface` | `#FFFFFF` | `#1A201F` | 卡片 |
| `surfaceAlt` | `#EDF1F0` | `#232A29` | 次级区块、表头 |
| `text` | `#1A1F1E` | `#E5EBE9` | 正文 |
| `muted` | `#5B6563` | `#9AA6A3` | 说明、次要时间 |
| `outline` | `#D3DAD8` | `#2E3735` | 分隔线、描边 |
| `due` | `#9A5B00` | `#F2B45A` | 到期（可以测了） |
| `overdue` | `#B3261E` | `#F2B8B5` | 逾期未测、错误 |
| `done` | `#2E6B30` | `#8FD18F` | 已确认 / 已录入 |
| `missed` | `#7A4A2A` | `#D9A88A` | 漏测、跳过、未完成 |
| `uncertain` | `#5B45A8` | `#C3B3FF` | 计时不确定、补填时间 |

状态永远“颜色 + 文字”同时出现，不单靠颜色区分。

## 2. 字号层级（sp / px 相同数值）

| 层级 | 大小/字重 | 用途 |
| --- | --- | --- |
| Display | 34 / 600，等宽数字 | 运行页全局计时 |
| Title | 20 / 600 | 当前步骤标题、页面标题 |
| Body | 16 / 400 | 说明、表格 |
| Label | 14 / 500 | 按钮、标签、状态 |
| Caption | 12 / 400 | 墙上时间、次要信息 |

所有时间与数值使用等宽数字（`tnum`）。间距基数 4：4 / 8 / 12 / 16 / 24。圆角 12（卡片）、20（按钮）。触控目标 ≥ 48dp。

## 3. 术语（界面用语 ↔ 契约用语）

| 界面 | 契约 | 说明 |
| --- | --- | --- |
| 实验 | 运行 run | “开始实验”“结束实验” |
| 步骤文件 | protocol | |
| 计时起点 | 锚点 anchor | 全局起点固定叫“开始”；其它用步骤文件里的 `label` |
| 确认完成 | step_confirmed | 不用“下一步”，强调是人确认的 |
| 采样 / 第 N 次 | sample point | |
| 计划 / 实测 / 录入 | planned / measured / entered | 三个时刻始终用这三个词 |
| 漏测 | missed | |
| 现象 | observation | |

## 4. 时间显示

- 经过时间：`+MM:SS`，≥1 小时 `+H:MM:SS`；起点未建立显示“未建立”（`muted` 色），**不显示 +00:00**。
- 墙上时间：`HH:mm:ss`；跨日时前置 `MM-dd`。
- 一个时刻同时出现多种表达时顺序固定：`墙上时间 · 全局 · 相对某起点`，如 `14:05:20 · +05:20 · mix +02:20`。
- `user_entered` 的时刻后加“（补填）”，`wall_estimate` 加“（估算）”，用 `uncertain` 色。

## 5. 采样点状态

| 状态 | 判定 | 文案 | 颜色 |
| --- | --- | --- | --- |
| 未到 | open 且 现在 < 计划 | 还有 MM:SS | muted |
| 到期 | open 且 计划 ≤ 现在 < 计划+60 秒 | 到期 | due |
| 逾期 | open 且 现在 ≥ 计划+60 秒 | 逾期 MM:SS | overdue |
| 已录入 | recorded | 数值 + 偏差 | done |
| 漏测 | missed | 漏测（理由） | missed |

## 6. 操作反馈

- 改变记录的操作（确认、录入、漏测、结束）都在成功后给一行提示；被拒绝时显示核心返回的原因原文。
- 不可撤销的操作（结束实验、跳过、标记漏测）先确认；结束确认框必须逐条列出待处置采样点。
- 重复点击不产生第二条记录（核心按动作 ID 去重）。
- 步骤确认后按钮原位换成下一步，新步骤出现后 1 秒内“确认完成”不可用，防止连点把下一步也确认掉（2026-10-08 模拟器实测发现）。
- 单选、勾选的整行（含文字）都是点击区域。
