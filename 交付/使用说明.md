# 实验记录（LabRun）使用说明（手机 1.1.1 / 电脑 1.1.0）

手机负责实验现场：按步骤提示操作、到点提醒测量、随时记录现象；电脑负责查看、整理、出报告。两边之间用一个导出包（`.labrun.zip`）传递，不需要联网、不需要账号。

## 一、安装

| 端 | 文件 | 说明 |
| --- | --- | --- |
| 安卓 | `安卓/LabRun-实验记录-1.1.1.apk` | Android 8.0 及以上。传到手机后点开安装，按提示允许“安装未知来源应用” |
| 电脑 | `电脑/LabRun-实验记录电脑端-1.1.0.msi` | Windows 安装包，装好后开始菜单里有“实验记录” |
| 电脑（免安装） | `电脑/LabRun-实验记录电脑端-1.1.0-免安装版.zip` | 解压到任意位置，运行 `LabRun\LabRun.exe` |

**手机首次打开请务必：**

1. 首页如出现“通知未开启”，点“开启”并允许——否则到点不会提醒。
2. 在系统设置里把“实验记录”的电池优化设为“不限制/无限制”（各品牌叫法不同：小米“省电策略→无限制”，华为“应用启动管理→手动管理并全部允许”，OPPO/vivo“后台耗电管理→允许后台运行”）。部分国产系统会在锁屏后限制后台，影响提醒准时。
3. 正式实验前，先用 `步骤文件示例/全功能测试.protocol.json` 在自己手机上锁屏试一轮，确认提醒能准时响。

## 二、准备步骤文件

1. 打开 `步骤文件示例/ChatGPT步骤文件提示词.md`，把整段提示词加上你的实验描述发给 ChatGPT。
2. 把回复的 JSON 存成 `xxx.protocol.json`，传到手机。
3. 手机首页“导入步骤文件”→ 选择该文件。有错误时会逐条列出位置和原因，改好再导入；没有错误才能开始。

几个概念：

- **计时起点**：点“开始实验”是全局起点；“某步完成后开始计时”是局部起点（确认该步时自动建立）；临场才知道的起点（如“看到沉淀时”）在运行页手动“建立”，可以回填更早的时刻。
- **采样计划**：相对某个起点的固定时刻（如 +1:00、+2:00、+3:00），起点建立时生成。到点手机提醒，你测量后录入；**不会自动填数，也不会因为晚录而顺延**。
- **步骤计划时间**：某步“起点后 X 秒再做”，到点提醒“可以开始”，但永远要你自己点“确认完成”。

## 三、做实验（手机）

- **界面布局**：顶部固定显示总计时和**最近建立的一个**计时起点（全部起点及“更正”在“时间线”页）；底部固定两个大按钮“记录现象”“确认完成”，戴手套也好按。“全部步骤”默认收起，点“展开”查看。
- **确认完成**：做完当前步骤再点。刚切到新步骤的 1 秒内按钮不可点，防止连点把下一步也确认掉。
- **采样**：采样一到点，顶部出现闪烁的“该测量了”色块（逾期变红），任何页签都看得到，App 在前台时手机还会振动；点色块直接录入。“操作”页预告下一次测量；“采样”页是完整测量表。点待测的一行录入：默认记“现在测的”，测完隔了一会儿才录，选“更早”填实际测量时刻。三个时刻（计划 / 实测 / 录入）都会保存。
- **计划外测量**：“采样”页每个计划右侧的“＋计划外”，按该计划的列补记一条，不占用计划点。
- **计划外测量表（自定义时间表）**：步骤文件里没有、临场才想测的东西，在“采样”页顶部“＋新建计划外测量表”：
  - 起表名，自定义 1–10 列（名称、小数/整数/文字、单位）；
  - **手动**：想记就点“＋记录一行”（“操作”页也有快捷按钮），时间自动记下，也可补填更早的测量时刻；
  - **定时**：设间隔（秒或分，至少 5 秒）和次数（最多 500），从建表那一刻起第 1 次、之后每隔一个间隔提醒一次；可中途“停止”——未到点的取消（不算漏测），已到点未测的保留；
  - 每张表自动生成“时间表”：每行一个时刻（测量时刻、全局时间、相对建表时刻、录入时刻）+ 你定义的各列 + 状态。录错同样可以更正或作废。
- **漏测**：录入框里“标记漏测”。结束实验时还没测的点会逐条列出，确认后记为漏测、值留空。
- **现象**：底部“记录现象”，可写文字、拍照、填更早的发生时间，可关联当前步骤。不会推进步骤。
- **跳过**：“跳过此步…”，必须填理由。负责建立起点的步骤不能跳过。
- **结束实验**：右上角。确认最后一步不会自动结束。
- 离开 App、锁屏、被系统杀掉都不影响计时；回来时自动恢复。手机重启后会标“部分时间为估算”。

## 四、录错了怎么办（更正）

原记录永远保留，更正只是追加一条记录。表格和报告显示更正后的值，并标注“已更正”，附完整更正记录（何时、改前改后、理由）。

| 想改什么 | 在哪里 | 备注 |
| --- | --- | --- |
| 测量值 / 实测时刻 | 测量表点那一行 | 可多次更正 |
| 这条测量根本不该记 | 同上 →“作废” | 进行中该点恢复待测，可重录；结束后记为漏测 |
| 误点了漏测 | 点漏测的那一行 | 仅进行中 |
| 误点了确认完成 | “全部步骤”里点最近确认的那一步 | 仅进行中；该步建立的起点下若已有采样，请改用“更正起点时刻” |
| 起点时刻不对 | 运行页“时间线”页的“计时起点”或详情页“更正”标签 | 计划采样时刻随之移动，偏差重算；全局起点不能改 |
| 现象写错 | 点现象卡片 | 照片不能改，整条有误请作废 |

作废、撤销、更正起点必须填理由。**实验结束后仍可更正**数值、现象和起点时刻，但不能新增记录。

## 五、导出与电脑端

手机详情页“导出”有三种格式：

- **数据包**（`.labrun.zip`）：完整原始记录和照片，给电脑端导入。
- **HTML 报告**：含照片和更正记录，可直接在手机上打开，用浏览器“打印 → 另存为 PDF”。
- **Excel**：概要、测量表，**每个采样计划和每张计划外测量表各一个“表·名称”时间表工作表**，以及时间线、现象、步骤、计时起点、更正记录。

电脑端：“导入导出包…”（`Ctrl+O`）选择 `.labrun.zip`，可一次选多个。

- 同一个包导入两次只保留一份；同一个实验后来又更正过、重新导出，会作为“新修订”并存，不覆盖旧的。
- 左侧可检索（`Ctrl+F`，匹配标题、现象文字、步骤名）和筛选；右侧可查看测量表（含折线图）、时间线、现象照片、步骤、起点与更正，并导出 HTML / Excel / CSV。
- 实验库默认在 `%APPDATA%\LabRun\library`，里面保存原始导出包，可以整体备份。

## 六、已知限制

- 提醒准时度依赖手机系统，模拟器实测为毫秒级；国产系统在锁屏和省电模式下的表现需要你在自己手机上确认。重启手机后，系统要等开机完成才会补发错过的提醒（模拟器上约晚 17 秒）。
- 同一部手机同时只能进行一个实验。
- 手机和电脑之间没有自动同步，需要手动传导出包。
- 安卓安装包用本项目自己的签名，以后的更新必须用同一个签名才能覆盖安装（签名文件见开发说明，请妥善备份）。
